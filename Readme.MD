# **Alphable**

Alphable is an STM32 12u alpha stagger PCB with leafspring tadpole mounting

The goal of this PCB is to have a basic in stock 12u alpha stagger PCB

### In this repo you will find:
```
- Layout options
- Images of PCB
- Firmware
- STEP model of PCB
- Edgecuts
```
