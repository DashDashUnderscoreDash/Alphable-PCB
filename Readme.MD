# **Alphable**

Alphable is an STM32 12u alpha stagger PCB with leafspring tadpole mounting

The goal of this PCB is to have a basic in stock 12u alpha stagger PCB

8u support via 8u stab positions was attempted but I messed up the footprint and it is not possible to install them. There is a new 8u bar in production and hopefully more in the future that will utilize the 6u stab positions. Those will work on this PCB. If I decide to stock this again in the future I will correct the 8u stab placement

### In this repo you will find:
```
- Layout options
- Images of PCB - Front only for now
- Firmware
- STEP model of PCB
- Edgecuts
```
